# 부적합 처리 요청

제조팀이 부품 라벨이나 도면 사진을 올리면 '부적합 처리요청' 메신저방에 붙여넣을 메시지를 자동으로 작성해 주는 페이지입니다.

```
1. 프로젝트명
2. 품번
3. 수량
4. 불량내용   ← 직접 입력
5. 귀책
```

## 사용법

1. **사진 찍기** 또는 **앨범에서 선택**을 누르고 라벨이나 도면 사진을 올립니다.
2. 읽힌 칸에는 초록색 '자동 인식' 표시가 붙고, 확인이 필요한 칸에는 노란색 '확인 필요' 표시가 붙습니다. 빈 칸은 분홍색입니다.
3. **불량내용**을 적습니다. 다른 칸도 직접 고치거나 검색해서 고를 수 있습니다(초성 검색 가능).
4. **복사**를 누르고 메신저방에 붙여넣습니다.

사진이 없을 때는 칸을 직접 입력해도 됩니다.

## 사진을 읽는 순서

모든 처리는 휴대폰 안에서 이루어집니다. 서버로 보내는 것도 없고 비용도 들지 않습니다.

1. **QR·바코드** (zxing-wasm): QR에 들어 있는 품번을 바로 씁니다. QR 기울기로 사진 방향도 알아냅니다.
2. **글자 인식** (Tesseract.js, 영어+한글): 프로젝트명, 수량, 업체명을 찾습니다. 라벨은 두 가지 방식으로 읽어서 결과를 서로 비교합니다.
3. 품번을 아직 못 찾았으면 **도면 표제란**(오른쪽 아래)을 잘라 확대해서 읽고, 그래도 안 되면 흐림 보정을 해서 다시 읽습니다. 모니터를 찍은 사진의 물결무늬 대응입니다.
4. 읽은 글자는 구글시트 목록(품번, 프로젝트, 귀책)과 대조해서 O↔0, I↔1처럼 헷갈리기 쉬운 글자를 바로잡습니다. 후보가 여러 개면 버튼으로 보여줍니다.

처음 한 번은 인식 도구 약 5MB를 내려받습니다. 이후에는 휴대폰에 저장된 것을 씁니다.

## 데이터

품질팀 '부적합 양식 변환기'와 같은 구글시트(링크 공유 '보기')를 읽습니다. 셀 위치가 아니라 **제목 글자**로 열을 찾으므로 행이나 열이 옮겨져도 동작합니다. 연도가 바뀌면 `참조(올해)` → gid → `참조(작년)` 순서로 찾습니다.

| 데이터 | 시트 |
|---|---|
| 품번 / 품명 | 품명/품번 (제목 '품번', '품명') |
| 프로젝트 발주명 | 참조(연도) L:M ('PROJECT DESC (발주명)' / 'TYPE') |
| 귀책 목록 | 참조(연도) AD:AE ('대분류' / '세부귀책') |

## 고칠 곳

`index.html` 맨 위 `CONFIG`만 고치면 됩니다.

- **업체 이름이 시트 이름과 다를 때:** `VENDOR_ALIAS`에 `'라벨 표기': '시트 이름'`을 추가합니다. 왼쪽은 (주)·㈜·주식회사·공백·점을 뺀 글자로 적습니다.
  예: `'브이피시스템': 'VP시스템'`
- **시트 주소가 바뀌었을 때:** `SHEET_ID`, `gid`를 바꿉니다.
