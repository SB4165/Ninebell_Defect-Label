# 부적합 처리 요청

제조팀이 부품 라벨이나 도면 사진을 올리면 '부적합 처리요청' 메신저방에 붙여넣을 메시지를 자동으로 작성해 주는 페이지입니다.

```
1. 프로젝트명 : ECP349
2. 품번 : EEAP-T00B1-0
3. 수량 : 1 EA
4. 불량내용 : 탭 누락      ← 직접 입력
5. 귀책 : 우신테크
6. 요청자 : 곽승범        ← 한 번 고르면 다음에도 그대로
```

## 사용법

1. **사진 찍기** 또는 **앨범에서 선택**을 누르고 라벨이나 도면 사진을 올립니다.
2. 읽힌 칸에는 초록색 '자동 인식' 표시가 붙고, 확인이 필요한 칸에는 노란색 '확인 필요' 표시가 붙습니다. 빈 칸은 분홍색입니다.
3. **불량내용**을 적고 **요청자**를 고릅니다. 다른 칸도 직접 고치거나 검색해서 고를 수 있습니다. 초성 검색이 되고, `ㄳㅂ`처럼 자판이 합쳐 버린 초성도 `ㄱㅅㅂ`으로 풀어서 찾습니다.
4. **복사**를 누르고 메신저방에 붙여넣습니다.

사진이 없을 때는 칸을 직접 입력해도 됩니다.

## 앱으로 설치 (홈 화면 아이콘)

같은 주소의 같은 페이지를 홈 화면 아이콘으로 열 수 있습니다. 주소창 없이 전체 화면으로 열리고, 인식 도구를 휴대폰에 저장해 두어 바로 시작합니다.

- **안드로이드 (크롬·삼성 인터넷):** 화면 위 안내 줄의 **설치** 버튼을 누릅니다. 안 보이면 크롬 메뉴 ⋮ → **앱 설치** 또는 **홈 화면에 추가**.
- **아이폰 (사파리):** 아래 **공유** 버튼 → **홈 화면에 추가**.
- **카카오톡 등 메신저에서 링크를 연 경우:** 설치가 안 되므로 크롬이나 사파리로 다시 엽니다 (화면 위 안내 참고).

구글시트 데이터와 학습 기록은 저장하지 않고 열 때마다 새로 불러오므로 항상 실시간입니다. GitHub에 수정 파일을 올리면 설치한 앱에도 바로 반영됩니다 (인터넷이 느릴 때는 다음에 열 때 반영). 관련 파일: `manifest.webmanifest`(앱 이름·아이콘), `sw.js`(인식 도구 저장), `icons/`.

## 사진을 읽는 순서

모든 처리는 휴대폰 안에서 이루어집니다. 서버로 보내는 것도 없고 비용도 들지 않습니다.

1. **QR·바코드** (zxing-wasm): QR에 들어 있는 품번을 바로 씁니다. QR 기울기로 사진 방향도 알아냅니다.
2. **글자 인식** (Tesseract.js, 영어+한글): 프로젝트명, 수량, 업체명을 찾습니다. 라벨은 두 가지 방식으로 읽어서 결과를 서로 비교합니다.
3. 품번을 아직 못 찾았으면 **도면 표제란**(오른쪽 아래)을 잘라 확대해서 읽고, 그래도 안 되면 흐림 보정을 해서 다시 읽습니다. 모니터를 찍은 사진의 물결무늬 대응입니다.
4. 읽은 글자는 구글시트 목록(품번, 프로젝트, 귀책)과 대조해서 O↔0, I↔1처럼 헷갈리기 쉬운 글자를 바로잡습니다. 후보가 여러 개면 버튼으로 보여줍니다.

처음 한 번은 인식 도구 약 5MB를 내려받습니다. 이후에는 휴대폰에 저장된 것을 씁니다.

### 속도

- 페이지를 열자마자 인식 도구를 미리 준비하고, QR을 읽는 동안 글자 인식기도 같이 준비합니다.
- 코어 4개·메모리 4GB 이상인 휴대폰은 글자 인식기를 2개 띄워 두 가지 읽기를 동시에 합니다.
- 라벨을 잘라낸 뒤 상자 면·그림자 같은 큰 검은 덩어리를 지우고 읽습니다. 글자 인식이 이런 곳에서 오래 헤매지 않습니다.
- 첫 번째 읽기에서 프로젝트·귀책·수량을 다 찾으면 두 번째 읽기는 건너뜁니다 (인식기 1개일 때).
- 라벨 사진에서는 도면 표제란 확대 읽기를 하지 않습니다 (도면으로 보일 때만).

## 학습 기록 (사람이 확인한 값 공유)

**복사**를 누르면 그때 칸에 있던 값(사람이 확인·수정한 값)이 구글시트 '부적합처리요청_학습기록'에 한 줄 쌓입니다. 다음부터는 모든 휴대폰이 이 기록을 씁니다.

| 열쇠 | 채우는 칸 | 언제 |
|---|---|---|
| 발주번호 (라벨의 PUR 뒤 숫자 10자리) | 프로젝트, 귀책 | 사진에서 읽은 값과 다르면 기록이 우선 (파란 '이전 기록' 표시) |
| 품번 | 프로젝트, 귀책 | 빈 칸이나 '확인 필요' 칸만 (노란 표시). 품번을 직접 골라도 채워 줌 |

- 귀책이 '확인요청'인 기록은 학습에 쓰지 않습니다.
- 잘못 들어간 기록은 기록 시트에서 그 줄을 지우면 됩니다.
- 인터넷이 끊겨 있으면 휴대폰에 모아 두었다가 다음에 보냅니다.
- 켜는 법: `학습기록_AppsScript.gs`를 Apps Script 웹 앱으로 배포하고, 그 주소를 `CONFIG.LEARN_URL`에 넣습니다. 비워 두면 꺼집니다.

## 데이터

품질팀 '부적합 양식 변환기'와 같은 구글시트(링크 공유 '보기')를 읽습니다. 셀 위치가 아니라 **제목 글자**로 열을 찾으므로 행이나 열이 옮겨져도 동작합니다. 연도가 바뀌면 `참조(올해)` → gid → `참조(작년)` 순서로 찾습니다.

| 데이터 | 시트 |
|---|---|
| 품번 / 품명 / 요청자 | 품명/품번 A:L, 행 수 제한 없음 (제목 '품번', '품명', '발견자'(F열)) |
| 프로젝트 발주명 | 참조(연도) L:M ('PROJECT DESC (발주명)' / 'TYPE') |
| 귀책 목록 | 참조(연도) AD:AE ('대분류' / '세부귀책') |

## 고칠 곳

`index.html` 맨 위 `CONFIG`만 고치면 됩니다.

- **업체 이름이 시트 이름과 다를 때:** `VENDOR_ALIAS`에 `'라벨 표기': '시트 이름'`을 추가합니다. 왼쪽은 (주)·㈜·주식회사·공백·점을 뺀 글자로 적습니다.
  예: `'브이피시스템': 'VP시스템'`
- **시트 주소가 바뀌었을 때:** `SHEET_ID`, `gid`를 바꿉니다.
- **인식 도구 버전을 바꿨을 때:** `sw.js` 맨 위 `VERSION`을 올립니다 (예: `'v1'` → `'v2'`). 휴대폰에 저장된 옛 도구를 지웁니다.
- **학습 기록 주소:** `LEARN_URL`에 Apps Script 웹 앱 주소(…/exec)를 넣습니다.
